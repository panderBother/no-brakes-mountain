# 无刹车山道

纯代码的 3D 山路赛车网页原型。赛车、蜿蜒道路、山体、树木、护栏、天气和爆炸由代码生成，音效通过 Web Audio 合成，无需模型、贴图或音频素材。使用 JavaScript + Three.js + Vite；Three.js 随本地构建打包，运行时不依赖 CDN。技术路线已从原计划的 Godot 调整为 Web 技术，后续通过 Electron 包装桌面版。

## 在线试玩与发布

- 在线试玩：[无刹车山道](https://panderbother.github.io/no-brakes-mountain/)
- 源码：[panderBother/no-brakes-mountain](https://github.com/panderBother/no-brakes-mountain)
- 构建与部署：[GitHub Actions](https://github.com/panderBother/no-brakes-mountain/actions/workflows/deploy-pages.yml)

推送到 `main` 后，GitHub Actions 使用 Node.js 22 执行 `npm ci`、`npm test` 和 `npm run build`，全部成功后将 `dist/` 部署到 GitHub Pages。拉取请求只做测试和构建。仓库的 Pages 发布来源设为 GitHub Actions；具体配置见 [GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。构建使用相对资源路径，支持仓库子目录和后续桌面壳。

建议使用电脑浏览器和键盘试玩；手机可使用画面中的触控方向键。游戏需要浏览器支持 WebGL。

## 运行网页版

需要本机已安装支持 Vite 的 Node.js（20.19+ 或 22.12+）。在项目目录运行：

```powershell
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5173>。生产构建及预览：

也可以双击 `启动网页版.cmd`：已运行的服务会直接打开，未运行时启动开发服务并打开浏览器。

```powershell
npm run build
npm run preview
```

预览地址为 <http://127.0.0.1:4173>。构建结果位于 `dist/`，发布到支持静态文件的服务器即可；直接双击 HTML 可能受浏览器模块加载限制。

## 玩法

- `A / D` 或左右方向键：转向。车辆持续自动加速，没有刹车。
- `空格`：使用有限次数的慢动作，从第 4 关开始引入。慢动作期间关卡倒计时正常流逝。
- `Esc`：暂停 / 继续；`R`：重试当前关卡。
- 护栏碰撞仅减约3 km/h，路障仅减约4 km/h，不损伤车辆。150 km/h起可撞断室外护栏，缺口保留到本次结束。
- 限时按理想通关时间加缓冲时间计算。到时未过终点，车辆爆炸。
- 九关均可从选关界面预览，难度逐步增加：山间公路、连续 S 弯、悬崖公路、九曲发卡弯、雨夜山路、雪山险道、隧道与断桥、极限盘山路、最终死亡山道。

当前为V0.8极限递增版：第一关150 km/h起跑，加速度每模拟秒+4.20 km/h；九关分别提高起速和加速度，最终关286/+9.40，后期增幅更大；普通道路宽 26–28 米，悬崖段、桥面、隧道逐级收窄，隧道最窄 5.8 米。九关限时为32–35秒，护栏破坏阈值为 150 km/h。

道路和天气分区保持固定，路障随每次出发的新种子在前方动态生成，身后障碍及时移除。每组障碍留有净空通道，桥口保留安全区域；不会随机生成封死的横墙。显式传入种子的测试可重复同一布局。新版本成绩单独保存，并记录成绩对应的障碍种子。

键盘和触控方向采用渐进响应：短按小幅修正，持续按住约半秒后逐渐达到大转向，释放和反打快速回正。干路路障组间距52–80米，湿滑、雪地和薄冰适当增加变线距离，路障更常截断中线。

允许360度转向与真正的反向行驶。普通宽路可操作掉头；镜头、路障和渐进加载随行驶方向切换。窄隧道与桥面不适合掉头，掉头不会重置倒计时。

三维场景按道路距离分段生成，只保留玩家附近及前方的片段，回收身后的网格和实例资源。山脊、岩壁、雪地、湿路、隧道与桥梁分别生成，材质细节也由代码绘制。

音效在用户点击开始后启用，可在界面静音。关卡参数仍需真人试玩调校；“第一关很少有人通过”是难度目标，尚无玩家通关率统计。Electron 桌面入口已准备，本轮未生成桌面包。

## 后续打包桌面版

已准备 Electron 启动文件及 Windows portable 构建配置。本轮交付以网页试玩为主，未安装 Electron，也未验证桌面安装包。需要打包时再安装开发依赖：

```powershell
npm install -D electron electron-builder
npm run desktop:dev
```

生成 Windows 便携程序：

```powershell
npm run desktop:pack
```

输出目录为 `release/`。桌面壳加载本地 `dist/index.html`，禁用 Node 页面权限，开启上下文隔离和沙箱，并阻止新窗口及外部页面导航。
