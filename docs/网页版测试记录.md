## V0.8 九关极限递增版（2026-10-15）

28项自动化测试通过，生产构建成功。九关均提高起速和加速度，且关卡间增幅递增：150/4.20、160/4.50、172/4.90、186/5.40、202/6.00、220/6.70、240/7.50、262/8.40、286/9.40。限时分别33/35/35/33/33/32/32/32/32秒。理论沿路线无碰撞末速约277/301/327/352/383/420/460/512/565 km/h。

新增逐关对比与增幅递增断言。末关最大曲率转向需求约为能力的92.7%，第8关85.1%；后期修正余量更少。高曲率路段的随机通道根据转向余量限制额外横向变化，避免强制不可能的躲闪。起跳竖直速度加入道路坡度分量，修正高速度下下坡起跳虚高或上坡起跳过短的问题。

九关×8种子的72条参考路线均在时限内合法完成。前6关参考路线无碰撞；后3关按当前允许的无伤轻碰和破栏规则验证通关，不再声称全部零碰撞。无障碍九关仍有完整无碰撞参考路线。轻碰减速、破栏、渐进转向、掉头、双向断桥和超时爆炸回归通过。

真实浏览器逐个选择九关，起速/加速度/限时均与上述配置匹配，难度标签从高压逐步显示至绝境。第9关发车0.1383模拟秒时实测287.30002 km/h，与286+9.4×0.1383一致。速度条改为按本关理论末速自动设量程，避免超过450 km/h后仪表提前满格；控制台无异常。

这些是规则与参考策略验证，不构成真人通关率统计。以下旧版数据保留用于历史对照。

## V0.7 强加速与渐进转向版（2026-10-15）

`npm test`：27项通过；生产构建成功。第一关130 km/h、3.60 km/h每模拟秒、37秒限时；第九关175 km/h、4.80 km/h每模拟秒、48秒限时。普通路宽、碰撞轻微减速且不伤车、150 km/h破栏、完整掉头和超时爆炸保留。

新增SteeringInput供键盘和触控共用：短按轻柔起步，约半秒持续按住才达到大转向，松开及反打快速清除旧输入。150 km/h、100 ms短按再松开150 ms的固定步长检查中，车头转角从17.81°降为3.13°，横移从1.73 m降为0.26 m。真实Chrome方向键短按观察为约4.19°、0.35 m（浏览器事件与采样时刻略有差异）；持续按住仍可掉头后反向前进。

干路路障组距由88–136 m缩短至52–80 m，通道分布扩至中线两侧约7.2 m，较大的路障更常截断中线。湿地/雪地/薄冰分别保留66–94、78–106、90–118 m组距，限制横向变线幅度；禁止用随机封路制造必败。九关×8种子共72条参考路线仍无碰撞通关。

同一中线追踪、不做避障策略：旧版8个种子全部通过，0–3次碰撞；新版8个种子全部超时，13–19次碰撞。这证明原先的简易策略被限制，不能据此推算真人通关率。

为适应高速腾空，桥前后曲率平缓区扩展，断桥前180 m/后220 m禁止生成路障，避免车辆尚未落地就被迫变线。高密度路障的黑色斜纹改用InstancedMesh，并在回收时单独释放实例缓冲。

浏览器检查新版菜单/指南、实际键盘转向及390×844窄屏，无控制台异常。相同种子密集路段连续加载三轮，几何均104个、纹理均7个、常驻9块/26个路障，未逐轮增长；追踪的7个旧斜纹实例在卸载时全部触发dispose。历史V0.6及V0.5数据仅用于对照。

## V0.6 破栏与自由掉头版（2026-10-15）

`npm test`：23项通过；`npm run build`成功。普通路26–28米，窄路140米渐变；护栏减3 km/h，桶/路障架/岩石减4 km/h，取消碰撞损伤，150 km/h触发室外护栏破坏，超时爆炸保留。

规则测试覆盖：149/150/220 km/h门槛、正常/慢动作破栏、80/180/260 km/h下三类障碍不损伤车辆、30/60/120 FPS连续接触不重复减速、150 km/h普通路完整无碰撞掉头、真正反向移动、反向障碍碰撞、反向断桥、不可撞穿的隧道墙、重试恢复、超时爆炸，以及九关×8种子共72条无碰撞参考路线。

本机Chrome真实WebGL验证：160 km/h撞栏后为157.0175 km/h（包括该模拟步自动加速），车辆存活、耐久兼容字段100、3段护栏破坏；对应横梁/立柱/反光片共7个实例被隐藏。该区域卸载、回到原处重建后仍隐藏7实例，破坏记录保持3段。

逆向镜头验证：镜头在车后约10.25米、目标在车前约21.54米；加载范围切到回程侧（里程1100时约480–1248），只常驻8块。回程障碍恢复同一位置和类型，已撞障碍不会复活。

实际方向键操作验证了掉头后进度从7.27米降至1.14米，车头朝向反向，车辆仍可行驶。此操作有两次轻微擦碰；自动化另验证150 km/h在合理入弯位置可无碰撞掉头。没有用修改进度值冒充掉头。

UI检查：耐久条已改为破栏统计，指南已同步规则；390×844窄屏无页面水平溢出。超时界面通过缩短剩余时间检查，失败原因为timeout且仍播放爆炸；重试恢复95 km/h、零破栏和正向车头。此前未生成或验证桌面包。

纯代码 Web 原型，使用 JavaScript、Three.js、Vite 和 Web Audio。Electron 桌面入口已准备，尚未安装桌面依赖或生成桌面包。以下结果仅适用于本版；旧版低难度的时间与测试数据不再作为验收依据。

## 核心与难度

`npm test`：18 项全部通过。覆盖自由转向、高起速持续加速、护栏减速后恢复加速、一次性路障、150 km/h 撞毁、磨栏按模拟时间扣耐久、慢动作时钟与限次、暂停、超时爆炸、重试恢复、截止前终点与断桥。

九关起速 95–130 km/h，加速度 2.10–3.00 km/h 每模拟秒。无障碍、无撞、无慢动作完整参考运行实测为 45.40 / 47.32 / 49.04 / 50.09 / 50.80 / 52.79 / 53.81 / 56.53 / 58.02 秒。取整理想时间加固定缓冲后，限时为 57 / 59 / 60 / 61 / 61 / 63 / 63 / 66 / 68 秒。

九关 × 8 种子共 72 条有障碍参考路线均无碰撞、无慢动作通关。末速所需转向最高为控制极限的 70.9%，不存在必须穿墙或人为减速才能转过的弯道。第一关无转向、一直向左或一直向右策略都失败。

这些结果证明路线可行，不能据此推算真人首次通关率。第一关低通关率是设计目标，尚未开展玩家统计。

## 随机生成

核心测试检查了同种子复现、普通重试更换种子、前方生成、身后回收、道路范围与净空通道。独立追加九关 × 32 种子：11,888 个障碍无越界、通道侵入或断桥前后 160 m 安全区异常；物理记录常驻最多 16 个。

实际留出的通道至少 3.6 m，最窄隧道 3.8 m。新障碍在滚动窗口的远边生成；288 组检查中新生成距离最低约 380.86 m。该距离是生成距离，实际可见性另由镜头、弯道、雾和场景验证。

以每 3 m 与每 47 m 推进对比，72 组布局指纹一致，生成节奏不改变同种子的障碍位置、类型或通道。静态扫描未发现相隔 90 m 以上的路线相交或宽度重叠。

## 浏览器检查

当前本机 Chrome 检查：1440×900 桌面菜单与 390×844 窄屏菜单无页面水平溢出，九关卡片可选择，窄屏横向滚动。新版起速与加速度信息显示正常。

实际按钮与按键验证了发车、右方向键改变车辆朝向与偏移、暂停冻结驾驶时间、第四关空格进入 0.35 倍慢动作并扣一次机会、超时爆炸及失败界面、重试恢复起速/100耐久/完整限时/能力次数，并更换障碍种子。超时界面通过将剩余时间设置为接近截止来验证，不代替核心完整路线时间校验。

实际查看了森林、雨夜、雪山、悬崖、隧道及断桥截图。隧道内路宽 6 m、镜头约在路面上方 2.6 m，车身和前路可见。悬崖段缺失左护栏与8.8 m窄路相符。发现桥口坡面突变、被裁掉坡面上的植被漂浮，已分别改为130 m平滑过渡和实际地形三角形支撑。场景跳转使用诊断入口，不能代替真人驾驶。

## 渐进加载与 WebGL 资源

场景块长 96 m，前方 576 m、后方144 m。每帧远处队列最多补2块，检查5.5 ms软预算；单块生成不可中断，这不是严格帧耗时保证。车辆附近道路优先同步准备。

真实 WebGL 连续切换九关三轮，相同关卡/种子的几何计数保持一致（133–136个，最终关131个），纹理稳定为7；没有每轮固定增长。长关视角逐段推进时最多9个活动块，低于11上限，身后销毁数持续上升，到终点仅保留3块。独立Three对象审查验证独立几何、InstancedMesh实例缓冲、共享材质/纹理及最终阴影贴图的销毁调用。

生产构建成功。实际网页资源请求仅为127.0.0.1:4173，没有远程模型、图片、字体、声音或CDN。修复了新Three版本中的阴影类型兼容警告，重新加载后控制台无警告或异常。

## 本机性能采样

Chrome / ANGLE / AMD Radeon(TM) Graphics（D3D11），1366×768，高画质。持续60.001秒沿最终关的完整道路推进渲染视角，包含动态路障、雨雪转换、窄隧道、断桥及分段生成；车辆朝向由诊断采样直接沿道路设置，因此本项验证渲染性能，不是实际玩家通关。

排除前2秒后采样3,475帧：帧间隔中位16.70 ms、P95 17.00 ms、最大18.10 ms。活动分段3–9，纹理恒定7个，几何采样104–138个；到终点卸载计数48，资源没有随里程不断增长。完整数据保存在`.qa/performance-final.json`。采样后仅微调外坡轮廓，并复查最终桥口、雪山及菜单画面；该轮廓改动没有增加网格或改变渲染调度。

此结果适用于本机此次采样，不承诺所有硬件、分辨率或长时间游戏都达到相同表现。冷启动shader编译、浏览器后台恢复及不同设备仍需后续专项测试。
